# 观古定名 · 技术说明

## 一、介绍

**观古定名**是一个依据中国古籍取名字的程序。

命名依据取自《左传·桓公六年》的五类原则：

> 名有五：有信，有义，有象，有假，有类。

- **信**：用真实发生过的事做依据（出生时令、天气、纪念事件等）
- **义**：用希望孩子成为什么样的人来取名（品格、德行、志向）
- **象**：用自然界的物象表达愿景（山川、日月、草木等）
- **假**：借人造之物的文化含义取名（玉器、佩饰、礼器、乐器、文房等）
- **类**：按家族传承、辈分取名（字辈）

它的特点是**每个字都说得出依据**：候选名里的每个字都会给出「归属哪一类原则 + 依据是什么 +
出自哪一句」，并把引文分两档——`原文可核`（原文库确有该条，附书名与篇名）与`文化约定`
（有文献语境但未绑定单句原文）。**不把文化约定包装成原典引文。**

适用于新生儿取名、改名、笔名、字号的构思：输入姓氏和期望，得到若干可解释、可追溯的候选名。

## 二、使用方法

### 方式一：本地服务（推荐，有界面）

```bash
python mobile/server.py 6700
# 浏览器打开 http://127.0.0.1:6700/
```

Windows 上可直接双击 `启动取名服务.bat`。界面是三步表单：**取名对象 → 命名依据（五类，最多选 2 项）
→ 补充信息与约束**，其中第三步非必填。

只依赖 Python 标准库（`sqlite3` / `http.server` / `urllib`），**不需要 pip 安装任何东西**，
也不需要 Node 或构建工具。

### 方式二：命令行（不需要起服务）

```bash
python engine/engine.py --surname 林 --text "希望孩子聪慧好学、性格温润，有远大志向" --top 3
python engine/engine.py --surname 李 --fixed 知 --principles F02 --top 3
python engine/engine.py --surname 李 --fixed 知 --generation 乐 --top 3
python engine/engine.py --surname 李 --fixed 知 --len 1
python engine/engine.py --help
```

常用参数：

| 参数 | 含义 |
|---|---|
| `--surname` | 姓氏（支持复姓） |
| `--text` | 自由需求描述，如"希望孩子聪慧好学" |
| `--principles F01,F03` | 指定五类原则（F01 信 / F02 义 / F03 象 / F04 假 / F05 类），最多 2 项 |
| `--fixed 知` | **必用字**（硬约束：每个候选都必须包含） |
| `--generation 乐` | **字辈字**（硬约束，同上） |
| `--avoid 清明` | 避用字 |
| `--len 1` | 名字字数（单字名 / 双字名，默认双字） |
| `--gender` | 性别倾向（中性 / 偏男性 / 偏女性） |
| `--birth "冬天出生"` | 「信」的事实依据 |
| `--top N` | 返回几个候选 |
| `--seed N` | 固定随机种子（同输入同输出） |
| `--json` | 输出结构化 JSON，便于接入其他系统 |

### 例 2：指定原则 + 必用字

输入：

```bash
python engine/engine.py --surname 李 --fixed 知 --principles F02 --top 3
```

输出：

```
【1】李知厚   综合分 93.1
【2】李知健   综合分 92.1
【3】李知静   综合分 90.9
```

`--fixed` 是硬约束，每个候选都包含「知」。

### 例 3：字辈（类）+ 必用字

输入：

```bash
python engine/engine.py --surname 李 --fixed 知 --generation 乐 --top 3
```

输出：

```
【1】李知乐   综合分 90.5
【2】李乐知   综合分 89.6
```

两个硬约束都满足，且不会把「李知乐」和「李乐知」这类颠倒组合当成两个结果重复给出。

### 例 4：单字名 + 必用字 → 唯一答案；凑不出来则明确报错

输入：

```bash
python engine/engine.py --surname 李 --fixed 知 --len 1
```

输出：

```
【1】李知   综合分 83.3
```

输入：

```bash
python engine/engine.py --surname 李 --fixed 昭知 --len 1
```

输出：

```
生成失败： 单字名只能指定一个保留字/字辈字，当前指定了 2 个（昭、知）
```

约束凑不出来时**绝不静默降级**：若必用字是汉字但不在字库里，会直接报
`指定的字（龘）都不在字库中，无法作为保留字/字辈字使用`，而不是返回一批不含该字的名字。

## 四、边界声明

- 命名依据限于《左传·桓公六年》五类原则及其可解释的文化语义转化，**不启用算卦、起卦、卦象选字**。
- **不作**命运、财富、疾病等吉凶预测。
- 引文标注分两档：`原文可核`（原文库确有该条，附书名与篇名）与`文化约定`（有文献语境但未绑定单句原文）。
  **不把文化约定包装成原典引文。**
- 字库是人工核校的子集，不是《通用规范汉字表》全集；未被收录的字不会出现在候选里。
- 音律只按普通话评测，未考虑方言读音与姓氏古音。
- 名字的最终选择权在用户；程序提供的是可解释的候选与依据。
